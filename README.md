# DefiSneak

Tracks and alerts on Ethereum and Binance Smart Chain decentralized finance transactions and wallet balances in real-time.

DefiSneak is built to be simple and practical, focusing on doing one thing well.

**Why DefiSneak?**

- Tracks and alerts on Ethereum
- and Binance Smart Chain decentralized
- finance transactions and wallet balances

## Key Features

- Tracks and alerts on Ethereum
- and Binance Smart Chain decentralized
- finance transactions and wallet balances

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DefiSneak.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
